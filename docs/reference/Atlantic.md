# Atlantic core-top foram assemblages

A dataset containing over 1000 foram assemblages from the Atlantic from
Kucera et al (2005) and the 50m SST for the warmest season. Rare taxa
and co-located assemblages are removed.

## Usage

``` r
data(Atlantic)
```

## Format

A data frame with 1093 rows and 33 variables. summ50 is 50m water
temperature of the warmest season

## Source

- Foraminifera data
  [doi:10.1594/PANGAEA.227322](https://doi.org/10.1594/PANGAEA.227322)

- Sea surface temperature data from WOA13
  <http://data.nodc.noaa.gov/woa/WOA13/DATAv2/temperature/csv/decav/1.00/>
  file 'woa13_decav_t13mn01v2.csv.gz'
